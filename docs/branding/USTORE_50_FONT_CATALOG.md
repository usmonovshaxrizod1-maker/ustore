# UStorE — 50 haqiqiy shrift

50 ta alohida oilaga mansub WOFF2 fayl loyihaning `vendor/wordmark-fonts` papkasida saqlanadi. Qurilmaga shrift o‘rnatish yoki Google Fonts xizmatiga murojaat qilish talab etilmaydi.

Preview, saqlangan logo va PNG eksport bir xil `FontFace` faylidan foydalanadi. Yuklanish vaqtida yozuv o‘rnida holat ko‘rsatiladi; yuklanmagan yoki kerakli harflarni qo‘llamaydigan shrift boshqa font bilan yashirincha almashtirilmaydi. Shriftlar faqat tanlanganda yoki ro‘yxatda ko‘ringanda yuklanadi.

Barcha 50 shrift o‘zbek lotin yozuvini (Oʻ, Gʻ, Oʼ, Gʼ) va rus alifbosini, shu jumladan Ё/ё harflarini qo‘llaydi. O‘zbek kirillidagi Қ/Ғ/Ҳ kabi qo‘shimcha harflar ayrim oilalarda mavjud emas; bunday matn uchun UI mos shrift tanlashni so‘raydi. Montserrat kabi to‘liq qamrovli oilalar mavjud. Boshqa yozuvlar ham katalogdagi haqiqiy Unicode qamrovi bo‘yicha tekshiriladi.

Avval saqlangan 15 eski uslub IDsi va logotiplari saqlanadi. Yangi 50 uslubning IDlari o‘zgarmagan.
